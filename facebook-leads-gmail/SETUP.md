# Facebook Leads → Gmail forwarder

Пересылает лиды из Instant Form (Facebook) на почту клиентов. Источник данных — Google Sheets, куда лиды уже льются из Facebook. Никакого Meta App/webhook не требуется.

## Установка

1. Откройте Google-таблицу с лидами (тот аккаунт, где должно висеть авторство скрипта — `anton.kon.47@gmail.com`).
2. Расширения → Apps Script.
3. Вставьте содержимое `Code.gs` в редактор (замените стандартный `Code.gs`).
4. В блоке `CONFIG` укажите:
   - `SHEET_NAME` — имя листа с лидами.
   - `COLUMNS` — точные заголовки колонок (как в строке 1 таблицы).
   - `CLIENT_MAP` — соответствие `form_name` → email клиента (можно несколько через запятую).
5. Запустите функцию `checkForNewLeads` вручную один раз — Google запросит доступ к Gmail и Sheets, подтвердите под `anton.kon.47@gmail.com`.
6. В редакторе слева — иконка часов (Triggers) → Add trigger → функция `checkForNewLeads` → Time-driven → Minutes timer → Every 10 minutes → Save.

## Как это работает

- Каждые 10 минут скрипт проверяет новые строки в таблице.
- Для каждой новой строки ищет email клиента по названию формы (`CLIENT_MAP`); если формы нет в списке — письмо уйдёт на `FALLBACK_EMAIL`, чтобы лид не потерялся.
- Письмо отправляется через `GmailApp` от имени `anton.kon.47@gmail.com`.
- Обработанные строки помечаются датой в колонке "Отправлено" (или текстом ошибки, если отправка не удалась) — повторно не отправляются.

## Ограничения

- Лимит Gmail на отправку: ~100 писем/сутки для обычного аккаунта, 1500 — для Google Workspace.
- Проверьте, что заголовки колонок в `CONFIG.COLUMNS` совпадают с реальными в таблице (Facebook может называть их иначе в зависимости от способа интеграции — нативный экспорт, Zapier, Make и т.п.).
